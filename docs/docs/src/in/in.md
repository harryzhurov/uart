# UART

Проект UART разработан в качестве тестового задания для краткого ознакомления с языком программирования System Verilog, системой управления версиями Git Hub, инструмента автоматической сборки программных проектов SCons, написанием верификационного проекта и описания проекта с использованием инструмента MkDocs. 

Документация включает в себя только описание RTL и Testbench проектов.
