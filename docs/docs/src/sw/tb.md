# Основное

Верификационный тест написан с помощью разбиения на классы
(**Transactions**,**Generator**,**Driver**,**Monitor**,**Scoreboard**,**Environment**).

Подобный подход позволяет структурировать и делать единообразным подход к написанию
верификационных моделей. Как говорил один классик "*Лучше безобразно, но единообразно*".
